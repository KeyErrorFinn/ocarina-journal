# 1.3.0 release validation

Release date: 2026-11-25. This release adds the Settings page and the optional paired, read-only second screen,
plus map loading, priority, memory and reconnect improvements. See [CHANGELOG.md](../../CHANGELOG.md) and
[SECOND_SCREEN.md](../research/SECOND_SCREEN.md) for the final behaviour and its limits.

## Local checks

- Rust formatting, workspace Clippy with warnings denied and workspace tests passed on Windows. The six
  game-data tests and the real-install report/cache test ran against the available local game files. The copied
  game-file tree's exact Longshot binary version was not independently identified in this release run. The
  optional golden/reference and standalone-save comparisons skipped without their private inputs.
- Frontend types, ESLint, Prettier, production build, Content Security Policy checks and five browser-behaviour
  regressions passed. `pnpm check` now includes those regressions, so the existing CI also runs them.
- The browser tests use synthetic data and exercise the actual frontend modules: map downloads are deduplicated,
  only requested views are decoded, navigation waits for its destination, selected requests pause queued
  background downloads, decoded pictures are bounded, and the disconnected overlay survives hung/stale requests
  and reloads after recovery. They do not measure a real phone's throughput or browser memory.
- The second-screen crate's 18 socket/server integration tests cover pairing, unpaired asset isolation, command
  restrictions, origins, session persistence and sign-out, rate limiting, WebSockets and idle expiry. Short test
  durations stand in for the seven-day idle rule; no seven-day physical-device observation is claimed. Failed
  data-command responses are also checked to ensure private backend paths cannot leak to a browser.
- No new advisory was returned by the OSV batch query for the 18 newly introduced registry package versions.
  Existing GTK/glib and maintenance limitations remain documented in
  [DEPENDENCY_REVIEW.md](../research/DEPENDENCY_REVIEW.md). The glib source tripwire passed.
- Added exact-version licence notices for updated and additional Windows/Linux dependencies. Upstream MIT
  notices absent from packaged crates were obtained from their recorded source revisions. The new app/home-screen
  icons derive from the project's existing original logo; no game artwork was added.
- The Windows startup/policy smoke test passed with an isolated profile. It checks that the tested page is
  version 1.3.0, permits local blob/data pictures and refuses external pictures. Its fallback discovery is
  restricted to the spawned app's own WebView descendants, so another development copy cannot produce a false pass.

## Release gates

The published binaries must be built from the matching `v1.3.0` tag by the existing release workflow. Local
Windows checks do not replace Linux compilation, Unix-socket tests or startup verification. Hosted source CI
and release jobs remain unchanged; no branch protection is permanently disabled for this release.

Before publication, download the draft's Windows installer and Linux packages, verify GitHub asset digests,
inspect payloads and scan the corresponding source for private paths, credentials and game files. Include the
tagged source archive and SHA256SUMS. The private review prompt and `.local` development data must be excluded.

The Windows installer and Linux packages remain unsigned. The second screen uses plain HTTP on the user's own
network, requires explicit opt-in and pairing, and is not a public internet service. Real-phone home-screen
installation, mobile network recovery and live Linux Longshot gameplay are not fully verified by the synthetic
and hosted tests. Reddit announcements remain drafts until separately approved.
