# 1.4.0 release validation

This release adds Child/Adult progress to the map, a magic bean soil layer with ride routes, side-by-side markers where
they overlap, Hyrule Field spoilers, and Hyrule Castle's buried Skulltula, grotto and Gossip Stones. The game and saves
remain read-only.

## Local verification

- Windows workspace formatting, Clippy with warnings denied and workspace tests passed, including the tests that read
  a local game folder (85 tests, none failing). The bean reader found all ten soil spots with their rides (Zora's River:
  a 318 m loop with three stops), Rumor Hunt's reader found Hyrule Castle's grotto and three Gossip Stones for both
  ages and no landmarks in dungeons, and the era reader's tests passed.
- Frontend types, ESLint, Prettier, production build and thirteen browser regressions passed. New regressions cover
  bean spot naming, ride arrows following the route in order, grouping and un-grouping of overlapping markers with
  zoom, the shortened scrub name and the Hyrule Field tips, and a hand-confirmed age that fills in only where the game
  gives none (with "incomplete only" unable to bring the child-only Skulltula back on the Adult map).
- The release build was run against the player's own game files and saves: the bean layer, route and arrows, grouped
  markers, and the castle's grotto and stones were checked on the real maps. The paired-browser command list gained
  one read-only command (`get_bean_soil`); the other restrictions are unchanged.
- The release description is generated from CHANGELOG.md; 1.4.0 starts a new series, so it contains that version only.

## Publication gates and limits

The unchanged hosted workflow must pass Windows and Linux builds and startup checks for the immutable release tag.
Before publication inspect the downloaded packages and source, verify digests and attach the source archive and
SHA256SUMS.txt. Packages are unsigned. Local Windows checks do not establish Linux package installation or live Linux
gameplay. One original icon (magic bean soil) was added; no dependencies were added.
